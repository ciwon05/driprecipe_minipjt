# 원두 스펙 시트 · 에티오피아 예가체프 워시드

- 원두 ID: MD-01
- 로스터리: 메리드립 로스터스 (가상)
- 산지: 에티오피아 게데오 지역 예가체프
- 가공 방식: 워시드
- 로스팅 정도: 라이트
- 컵노트: 자스민, 레몬, 홍차
- 맛 프로필: 산미 5 · 단맛 3 · 바디 2

## 산지와 가공
예가체프는 에티오피아 남부의 해발 1,700~2,200m 고지대로, 꽃향과 밝은 산미로 잘 알려진 산지다. 워시드 가공은 과육을 벗긴 뒤 물에서 발효·세척해 말리는 방식이라 맛이 깨끗하고 산미의 윤곽이 또렷하다.

## 컵노트 설명
자스민 같은 꽃향이 먼저 올라오고, 레몬처럼 상큼한 산미가 이어진다. 식으면서 홍차 같은 가볍고 깔끔한 여운이 남는다. 바디는 가벼운 편이다.

## 로스터리 권장 레시피 (V60 기준)
| 항목 | 값 |
|---|---|
| 원두량 | 15g |
| 비율 | 1:16 (물 240g) |
| 물 온도 | 93℃ |
| 분쇄도 | 매버릭 2.0 기준 205클릭 |
| 목표 총 추출 시간 | 2분 30초 |

라이트 로스팅이라 원두가 단단하고 잘 녹아 나오지 않으므로, 비교적 높은 온도와 고운 분쇄도로 추출을 충분히 끌어낸다. 산미가 날카롭게 느껴지면 과소추출을 먼저 의심한다.
