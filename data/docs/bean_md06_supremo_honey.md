# 원두 스펙 시트 · 콜롬비아 수프리모 허니

- 원두 ID: MD-06
- 로스터리: 메리드립 로스터스 (가상)
- 산지: 콜롬비아 나리뇨
- 가공 방식: 허니
- 로스팅 정도: 미디엄
- 컵노트: 캐러멜, 사과, 밀크초콜릿
- 맛 프로필: 산미 3 · 단맛 4 · 바디 3

## 산지와 가공
나리뇨는 콜롬비아 남서부의 고지대 산지다. 수프리모는 콜롬비아의 생두 크기 등급 중 큰 쪽을 뜻한다. 허니 가공으로 점액질의 단맛을 살렸다.

## 컵노트 설명
캐러멜 같은 단맛과 사과 같은 부드러운 산미가 균형을 이루고, 밀크초콜릿 같은 여운이 남는다. 산미와 바디 모두 중간이라 처음 핸드드립을 하는 홈브루어에게 무난하다.

## 로스터리 권장 레시피 (V60 기준)
| 항목 | 값 |
|---|---|
| 원두량 | 15g |
| 비율 | 1:16 (물 240g) |
| 물 온도 | 91℃ |
| 분쇄도 | 매버릭 2.0 기준 218클릭 |
| 목표 총 추출 시간 | 2분 45초 |

미디엄 로스팅은 라이트보다 잘 녹아 나오므로 온도를 조금 낮추고 분쇄도를 조금 굵게 잡는다.
