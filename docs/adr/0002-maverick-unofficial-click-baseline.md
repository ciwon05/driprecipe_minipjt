# 매버릭 분쇄도는 비공식 커뮤니티 수치를 프로젝트 가정으로 쓴다

홀츠클로츠 매버릭은 제조사가 공개한 분쇄도 표가 없고, 커뮤니티 수치도 출처마다 크게 다르다(200~240클릭이라는 후기와 80~125라는 후기가 있다). 그래도 분쇄도를 클릭 수로 안내하려고, 매버릭 2.0 사용자 후기의 "핸드드립 200~240클릭"을 근거로 프로젝트 기준표를 직접 정했다. 0점은 버를 끝까지 닫은 지점이다. 원두마다 V60 기준 클릭 수를 이 범위 안에서 정하고, 다른 드리퍼는 칼리타 웨이브 +10 · 케멕스 +25 클릭으로 보정한다. 맛 교정 1단계는 ±10클릭, 증상이 반대로 바뀌면 ±5클릭, 허용 범위는 190~250클릭이다. 이 수치는 공식값처럼 보이면 안 되므로 RAG 문서와 답변 양쪽에 "비공식 시작값"임을 밝힌다.

## Consequences

- 매버릭 1.0은 클릭 의미가 같은지 확인되지 않아 지원하지 않는다.
- 공식 수치가 나오거나 다른 그라인더를 추가하면 이 기준표부터 바꾼다.
