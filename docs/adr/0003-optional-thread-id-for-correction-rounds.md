# 맛 교정 회차를 세기 위해 선택 필드 thread_id로 멀티턴을 지원한다

같은 원두로 맛 교정을 3회까지 하고 그래도 맛 증상이 남으면 다른 원두를 추천하기로 하면서, 앞 대화의 원두 · 현재 레시피 · 교정 회차를 기억해야 하게 됐다. 그래서 `POST /query`에 선택 필드 `thread_id`를 추가하고 LangGraph 체크포인터에 대화 상태를 저장한다. `thread_id`가 없으면 질문 한 번에 담긴 정보만으로 처리하므로 `question`만 보내는 제출 규약은 그대로 지켜진다. ADR 0001을 대체한다.

## Consequences

- `test_queries.csv`는 한 줄에 질문 하나라 멀티턴을 직접 담지 못한다. 반복 시나리오는 이력을 질문에 담아 쓴다(예: "케냐 AA로 세 번 교정했는데 아직도 셔요").
- 질문에 적힌 이력과 체크포인터의 상태가 다르면 어느 쪽을 믿을지 구현 때 정해야 한다.
