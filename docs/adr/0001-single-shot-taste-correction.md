# 맛 교정은 멀티턴 없이 질의 한 번으로 처리한다

제출 규약상 `POST /query`는 `question` 필드 하나만 받고 세션 식별자가 없다. 그래서 맛 교정에 필요한 원두, 내린 레시피, 맛 증상을 홈브루어가 질문 하나에 함께 적는 단발형으로 정했다. 빠진 정보가 있으면 에이전트가 무엇이 빠졌는지 되묻는 것을 정상 동작으로 본다.

## Considered Options

- 선택 필드 `thread_id`를 추가해 멀티턴 지원: 채점 쪽은 `question`만 보내므로 평가 세트로 검증되지 않아 기각했다.
